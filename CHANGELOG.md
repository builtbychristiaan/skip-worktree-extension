# Changelog

All notable changes to the Skip Worktree extension are documented in this file.

## [0.1.1] - 2026-06-19

### Added

- Skipped Files sidebar with activity bar view
- Status bar indicator with live skip-worktree count
- Command palette quick pick to browse, open, and unskip files
- Explorer context menu actions for skip and unskip (multi-select supported)
- Multi-root workspace support with files grouped by folder
- Confirmation dialog before unskipping all files

## [0.1.0] - 2026-06-19

### Added

- Initial release: skip and unskip tracked files via `git update-index --skip-worktree`
